System Failure Safety Fail-Closed By Design

SettleGraph's optional AI reasoner (engine/ai_reasoner.py) only ever proposes a hypothesis for an exception the deterministic matcher already could not resolve. The model never decides a match: its hypothesis is fed back through the deterministic invariant gate (verify_settlegraph_invariants) and only promotes to AI_RESOLVED_MATCH — never AUTO_MATCH — if every invariant passes.

Every failure path leaves the record exactly where the deterministic layer put it. A timeout, rate limit, refusal, malformed JSON, or invariant breach keeps the record as EXCEPTION.

Enforced in code and verified live in the Failure Sandbox.
