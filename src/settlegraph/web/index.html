By design

The optional AI reasoner (engine/ai_reasoner.py) only ever proposes a hypothesis for an exception the deterministic matcher already could not resolve. It never decides a match: the hypothesis is fed back through the same invariant gate and, if every invariant passes, promotes only to AI_RESOLVED_MATCH — never to AUTO_MATCH.

Every failure path leaves the record where the deterministic layer put it. A timeout, rate limit, refusal, malformed response, or invariant breach keeps it an EXCEPTION.

Enforced in code and exercised live in the Failure sandbox.
